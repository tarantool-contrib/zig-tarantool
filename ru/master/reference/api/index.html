    API by module¶

    This page lists the public declarations of the package, by module, with a line on each and a link to the page that shows it in use. The generated API reference has every declaration with its doc comment, its signature and its source: for example tarantool.box.Space, tarantool-client.Connection, msgpack.encode.

    @import("tarantool"), in a module only.

    Declaration Is See
    proc.exportProc(name, f) exports a plain Zig function as a stored procedure Stored procedures
    proc.exportRaw(name, f) exports fn(ctx, args, args_end) !c_int as a stored procedure Stored procedures
    proc.returnValue(ctx, value), proc.returnTuple(ctx, tuple) add a result to a call
    proc.fail(err, message) fails a raw procedure
    proc.RawProc the C type of a stored procedure
    box.Space a space: byName, insert, replace, get, delete, update, upsert, truncate, the *Discard variants, primary, index, indexById Spaces and indexes
    box.Index an index: get, min, max, count, len, bsize, random, select, iterator, cursor, range, top, update, extractKey Spaces and indexes
    box.Iterator, box.Cursor, box.Range(Row) walks over an index: owning, borrowing, typed
    box.Typed(Row) a space as rows of a named struct: put, insert, get, del, free Spaces and indexes
    box.info the state of the instance: status, isRo, waitRo, roReason, schemaVersion, lsn, slab Introspection
    box.Tuple, tuple.Tuple a tuple: get, field, decode, decodeRow, fieldCount, bsize, fieldIterator, new, update, deinit Spaces and indexes
    txn.transaction(f, args), txn.transactionWith(options, f, args) runs f in a transaction Transactions
    txn.Savepoint a savepoint: save, rollback Transactions
    txn.active, id, isolation, setIsolation, setTimeout, makeSync, alloc, allocSlice the active transaction
    seq.Sequence a sequence: byName, byId, next, current, set, reset Spaces and indexes
    keydef.KeyDef a key definition: init, compare, compareWithKey, extractKey Spaces and indexes
    fiber.spawn, spawnWithAttr, spawnDetached start a fiber Fibers
    fiber.Fiber(R) a fiber to join: join, cancel, wakeup, id, name, setName, csw
    fiber.FiberAttr, fiber.find, fiber.FiberInfo stack size; look up a fiber
    fiber.sleep, yield, reschedule, isCancelled, time, clock, ... the current fiber
    fiber.Channel(T) a bounded channel: send, recv, close Fibers
    cond.Cond a condition variable: wait, waitTimeout, waitUntil, signal, broadcast Fibers
    latch.Latch a mutex for fibers: lock, tryLock, unlock, withLock
    coio.wait, coio.close wait until a file descriptor is ready Fibers
    coio.call, coio.getAddrInfo run a function, or resolve a name, on a worker thread
    fiberio.io() a std.Io whose network I/O yields the fiber The client in a stored procedure
    lua.exportModule(name, defs) exports luaopen_<name> for require Lua modules
    lua.Lua, lua.Multi, lua.multi, lua.raiseErr the Lua stack, several results, errors
    trigger.onReplace, trigger.SpaceTrigger a trigger on the writes to a space Triggers
    trigger.onCommit, onRollback, onShutdown, removeShutdown triggers on a transaction and on the shutdown
    say.err, crit, warn, info, verbose, debug, sysError, enabled, stdLogFn the log Logging
    decimal.Decimal a decimal and its arithmetic Decimals and extensions
    region.allocator(), region.Savepoint the fiber region as an allocator Lifetimes
    err.lastError(), err.lastMessage(buf), err.setBoxError(code, message) the error of Tarantool Errors
    clock.realtime, monotonic, process, thread the system clocks Introspection
    symresolve.resolve(name) the address of a symbol that Tarantool does not export Introspection
    c the C API of Tarantool, declared in Zig Modules and layers
